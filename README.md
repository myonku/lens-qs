# lens-qs：无纸化检验台账

按**产品批（共享表单号＋完整样品型号）→ 工序填报组 → 检验单 → 版本**组织数据，各工序独立填报、修订和汇总。

本轮规则：

- 每道工序支持独立抽检：共用正常表单并增加抽检标记，批次/状态/统计按类型隔离。抽检不填损耗，由前端校验，后端不新增专属屏蔽。

- 撤销原生日期/时间列要求；SQLite 与 PostgreSQL 均保留 **TEXT 字符串存储**，统一格式。业务日期为 `YYYY-MM-DD`，准确时间点为 UTC `YYYY-MM-DDTHH:mm:ssZ`；旧纸面原文独立保留。
- 对无需拆批的工序，**不填批次就是整产品批检验**。同产品批同工序的后续提交必须检查整批重复、批号重复及整批/分批混用；具体 409 策略是本版设计建议。
- 保留每批损耗/数量变化原因、全部纸质栏目和 35 类×3 表面缺陷。人员与系统录入用户分别记录。
- 不要求跨工序子批次来源关系；前序未结束、跨工序数量不同均允许，各工序同名批号互不关联。

旧 `/api/forms` 仍会按全局唯一 `form_no` 合并更新，不能用于试录 v2 的同号多工序/多批次。当前接口细节见[归档接口文档](archive/2026-11-03/legacy/docs/api.md)，以代码为最终依据。
