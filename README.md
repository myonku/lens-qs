# lens-qs — 无纸化检验台账 v2

按生产批组织各工序独立填报的镜片检验记录。每道工序可自行拆分检验批次，部分批次可以先进入后序；系统不要求等待整批，不保存无法采集的跨工序实物来源关系。

保存即生效，每次修改保留内容版本与操作历史。正常/抽检共用生产批身份，按工序和检验类型独立登记、占用批号和统计。纸面计量单位固定为“片”。

以下文档独立定义 v2 的业务与目标接口，不依赖归档约定，也不表示现有工程已实现或完成部署。审阅顺序建议为需求、功能、字段、系统设计和 API。

| [功能说明](docs/features.md) | 操作场景、录入/更正/取消、查询与计划能力 |
| [字段目录](docs/fields.md) | 全部纸面栏目、样品字段、35×3缺陷、数量变化与留痕 |

实施准备见[二次重建评估与计划](docs/rebuild-plan.md)：基于现有代码安排“清理与底层重构、功能再搭建”两轮工作及验收门槛。该计划不替代上述业务与接口规格，也不表示已开始实施。

Go后端采用模块化单体，目标支持SQLite和PostgreSQL。现有代码在backend/，评估与实施均以当前规格为依据，不以代码行为反推需求。Excel/CSV导出、打印/PDF和历史台账导入列为低优先级计划能力。
