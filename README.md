# lens-qs — 无纸化检验台账 v2

版本 **2.0.0**，数据库迁移至 **0006**。正式文档覆盖需求、公共约定、领域设计、接口和运行维护，可独立用于开发与对接。

Go 后端，SQLite/PostgreSQL 双库。按产品批→工序与检验类型填报组→检验单→不可覆盖版本组织资料。普通/抽检账户按 NORMAL/SAMPLING 隔离填报，管理员同样受填报类型约束；支持独立填报、正式修订、统计、历史时点报告及工序时间范围报告。

认证、账户、字典、解析、业务和报告接口统一 `/api/v2`，健康检查为 `/healthz`。前端根据登录/me返回的账户类型固定填报标记。日期仅保存经校验的规范值，继续使用TEXT，业务时区Asia/Shanghai，不另存日期原文；未知计数不补零，不由工序差额推导库存或损耗。
