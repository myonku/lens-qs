# 无纸化检验台账 v2 — 功能说明

本文按使用场景解释目标功能；字段和请求详见[字段目录](fields.md)及[API](api.md)，业务验收见[需求](requirements.md)。本文不标注代码实现率或部署状态。

## 1. 查找一批产品的检验记录

以共享表单号＋完整样品型号找到生产批；同号但型号不同分别登记。正常检验和抽检共用生产批身份，进入后按工序与检验类型分开显示。

每个工序独立建立检验批次，不要求选择前序来源。同样叫c的两个工序批次互不关联。某工序只完成部分检验批次时，下一工序仍可录入；后序记录先录、前序以后补录也可正常归档。

总览显示已经登记的组和单据、当前数量、缺项和填报状态。没有记录不解释为“尚未生产”，没有完整生产路线时不显示推测的整体进度。

## 2. 填写与补充一张检验单

一张单对应一个检验批次及固定机台/人员组合，不提供批次内部再分段。机台可以在多张单中复用；机台号不代替检验批号。整批工序留空批号；分批工序使用真实批号。同组整批/分批互斥，具名批号不能重复。

现场可以先填少量内容保存，后续继续补；集中录入可一次填完或批量新建。保存即生效，没有发布或审批按钮。每次成功保存形成新内容版本，旧版完整保留；同一单多次保存只以当前版统计，不重复累加历史数量。

身份暂缺时可保存未归组记录，在清单中继续补充。未归组记录不属于任何生产批/工序统计，选定归属后立即入统计；原先的内容和归组动作都有历史。绑定后身份录错按取消重建处理。

同组只允许一张有效整批单，或者多张批号不同的分批单。新建遇到已有批号提示补填原单，不自动覆盖。取消会释放占用但保留旧单证据；不同工序或类型同名批号不冲突。

## 3. 纸面栏目与系统操作者

保留单位、送检人/时间、检验人/时间、操机员、交接员。纸面人名按实际文字记录，代录账号单独留痕；按“张三检验的数量”和按“李四录入的记录”查询是两种不同的功能。

纸面单位固定为计量单位“片”，前端固定传入，后端仍拒绝其他值；不把用户所属部门填进这一栏。单位未知可以暂存并提示缺项，不隐式从账号补齐。

业务时间与录入时间分开。仅知日期时保留日期，准确时点才记录带时区时间；日期未知不以创建日代填。日期输入使用规范值，不另存任意日期文字。纸面时间更正与普通内容一样产生新版本。

## 4. 样品信息与辅助解析

样品原文完整保存，同时提供项目、型号、规格、大小、左右五项结构化输入，可人工修正用于检索和统计。项目M1/M2独立存在，不能因部件清单没有项目就删掉该字段。

辅助解析按token匹配，不要求固定书写顺序。解析不到的词保留并提示；没有别名时不把ND2猜成VID2。MONOC/BINOC/Rx等只作参考，缺失不阻止保存。完整参考部件号见[参考资料](reference-data.md)。

人工确认映射可供相同原文以后复用，但不会追溯更新已经保存的单据。解析和确认不自动改原文，不创建生产批，不改变单据归属。需要纠正原文时由用户明确保存新版本。

## 5. 计数、缺陷与数量变化

检验量、合格量、不合格量区分“未填”和“明确为零”。表头填报的三项 counts 是唯一统计来源，良率由服务端据此计算；分母未知/零或分子不完整、不可比时显示未知及原因。明细计数仅合计核对，不覆盖或补齐表头；仅改明细不改变表头统计。纸面数量声明及其独立原始值不另行录入、存储或回显。

每单保留35类缺陷×凹面/凸面/双面共105格，每格为具有该类缺陷的镜片数量。可有多行明细；提交明细数组是完整替换，不把它当作新的检验批次。缺陷跨类别可能重复，因此缺陷子项合计不能当作唯一不良件数。

损耗或数量变化允许只填原因、数量未知；保存说明不自动扣检验量和合格量。抽检不允许填写LOSS，前后端共同阻止，不能直接调API绕过。相邻工序的数量差异不自动生成损耗或库存。

## 6. 缺项、校验与并发提示

| 情况 | 使用者看到的行为 |
|---|---|
| 工序、单位、检验人、样品原文、明细有缺项 | 保存成功，返回缺项清单；不代表不能统计 |
| 项目未拆解、参考不匹配 | 可继续保存，之后人工核对 |
| 三项计数不平衡、缺陷与不合格量不同 | 保留原值并提示，不擅自修改 |
| 负数、非整数、非法日期、非“片”单位、抽检LOSS | 拒绝本次保存，指出字段；原内容保持 |
| 另一账号已经修改同单 | 版本冲突，重新读取并核对，不能盲目覆盖 |
| 网络断开后原样重试 | 原幂等键回放成功结果，不重复保存 |
| 批量任一单出错 | 全批回滚，指出失败项，不留下部分成功 |

完整度是资料检查，不表示生产完成、无数量矛盾或审批通过。所有工序使用完整字段布局，不预设未确认的工序必填组合。

## 7. 更正、取消与结束填报

更正直接保存新版本并更新当前统计。即使后序已有记录，也不冻结前序；前序改数不会自动改后序。历史可以看到谁在何时改了什么，两版可对比。

取消必须有原因，当前统计立即排除该单，历史仍在。取消不能代表实物退回或损耗。取消后如需重新登记，明确新建一张单，不能把旧历史抹去。

工序组可以“结束填报/重新开放”。结束只阻止新增或归入新单，已有单仍可补充、更正和取消。它只影响当前生产批、工序和类型，不代表其他批次或生产批整体完成。字段齐全不会自动结束填报。

## 8. 普通、抽检与管理员

NORMAL账户填正常记录，SAMPLING账户填抽检记录；管理员也只能填本账户类型。所有登录用户均可读两类，可修改同类型他人记录，每次留痕。管理员额外管理账号，不拥有隐式跨类型填报权。

登录返回固定填报标记，前端不提供随意切换。两类记录的批号占用、填报状态、统计和良率分别计算。正常组结束不影响抽检组继续登记；抽检不要求引用正常单ID。

管理员可创建/停用用户、重置密码、更改账户类型。停用或重置密码使会话失效，变更类型还清旧幂等结果；密码本身不随类型改变。账号改名/停用不改变业务历史中的操作者快照。

## 9. 查找、汇总与报告

| 功能 | 用途与口径 |
|---|---|
| 记录清单 | 按生产批、工序、类型、批号、机台、纸面人员、样品字段、系统账号、日期和缺项组合筛选 |
| 未归组/缺项/待拆解清单 | 使用相同记录列表筛选，保留完整详情，不以缓存充当业务记录 |
| 通用汇总 | 按工序、设备、样品五项、人员、业务日/月等组合，返回数量与加权良率 |
| 缺陷分布 | 35×3格分别汇总，未知不补零，不承诺唯一不良数 |
| 数量变化 | 仅当前版声明，已知量与未知条目分开，不称库存流水 |
| 工作量 | 纸面检验量、账号录入归属和系统保存次数分别定义，不能混用 |
| 生产批历史时点报告 | 还原当时各工序组和版本，取消/更正之后再查过去仍一致 |
| 工序日期范围报告 | 可跨生产批或限定某批，返回分页资料和完整范围小计，未知业务日单列 |
| 历史与日志 | 看每次完整内容、两版差异、操作者和原因 |

统计只取有效且已归组单据当前版本，取消/旧版不重复计量。所有数量按“片”；正常/抽检分区。跨工序相加只称检验工作量；产品批报告不能展示准确产量、库存、全流程良率或实物召回范围。

## 10. 低优先级计划

以下已纳入计划，但接口、模板与规模需在实施前定稿，不计作当前核心闭环的前置条件：

- Excel/CSV导出：筛选与版本集合可复核，未知和零分别表达，类型明确分区。
- 打印/PDF：保留纸面全部栏目、机台/批号、检验类型和系统留痕说明。
- 历史台账导入：预览和逐行错误、身份归组与防重确认，不静默覆盖已有单或补造来源关系。

## 11. 范围限制

不建立跨工序子批来源、收发/余额、精确库存、单片去重、实物追溯或全流程质量归因。不实现审批、MES/ERP/AOI集成、多租户或缺陷自动判定。复检/返工轮次、跨生产批混料和生产批身份合并需另行明确业务规则，不能由普通修改隐式支持。
