| 功能 | 交付 |
|---|---|
| 账户管理/会话/字典/解析 | 全部迁到/api/v2，已有账户密码保留 |
| 普通与抽检账户 | account_type自动填报类型、服务层越权校验、类型变更撤销会话/幂等 |

| 幂等与并发 | 事务内结果、强制版本、批量整体回滚 |
| 统计 | 正式版本唯一来源、类型分区、未知量/零区别、正确良率 |

| 工序范围报告 | 时间范围、限定/不限产品批、分页明细与全量小计 |

不包含前端工程、复检轮次、跨工序谱系、产品批合并、持久导出快照与审批。前端抽检标记和LOSS拦截由前端迁移实施；后端提供账户信息与通用校验。
