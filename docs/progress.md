## 4. 已收敛决策与范围

- 产品批身份只trim；同号不能隐式覆盖单据，空批号表示当前工序整批；草稿占用、重复/整分混用409、取消释放。
- 各工序和两类检验独立，不引入来源分配、交接余额或前序冻结。正式统计仅取未取消单的current_revision_id一次。
- counts是正式事实源；declared_counts和明细用于核对，缺失为未知，数量变化不自动扣改计数。数量算式与参考不匹配是提示，不是强制物料平衡。
- 日期/时点继续TEXT，严格格式、原文独立、Asia/Shanghai归日。SQLite默认内存临时存储并补齐URI连接配置。
- 类型权限以当前账户为准，普通/管理员都适用；同类型普通用户可以更正，发布修订/取消和组状态变更需原因、版本与审计。
- 历史回放从0006或显式清理建立的history_started_at开始；此前返回history_unavailable。通过as_of与返回的through_event_id固定报告视图。
- 旧双业务域/只读兼容和旧单暂存导入计划已被正式切换取代。0001–0005仅作为已发布升级链保留；0006删除旧域数据，清理需确认范围并先备份。

不在本期：外部前端工程、复检/返工轮次、跨工序谱系、产品批合并、库存、审批和持久导出快照。身份trim、未知数量可发布和数量枚举等为当前实现口径；修改时须更新需求/设计/API及相应验收，历史草案中未确认建议不自动成为额外业务要求。
