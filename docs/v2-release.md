# v2.0.0 发布说明

正式版本2.0.0，数据库迁移链0001–0006。当前接口、公共约定与业务规则分别见[API](api.md)、[公共设计](common-design.md)、[领域设计](design.md)。

## 能力

- NORMAL/SAMPLING账户固定填报类型，组/单变更按当前账户类型授权；管理员标记独立。类型变更撤销会话并清业务幂等缓存，密码保持。
- 产品批报告支持as_of历史回放与through_event_id固定视图，正式、初始草稿、修订草稿及取消独立展示；早于历史起点返回history_unavailable。
- 工序范围报告支持限定或不限产品批，分页明细与全范围正式小计分开，两种检验类型独立统计。
- 纸面全部栏目、105格缺陷、可空计数与数量变化共用内容模型；保存追加版本，发布决定正式统计资格。

日期设计约定：前端日期/时间选择组件提交规范值，后端校验后仅存规范日期/时点，不再保留日期原文。此项为文档确认的目标契约，实现及存量结构适配待实施；不改变样品原文保留。

## 调用与维护

认证、用户、字典、解析、业务和报告统一 `/api/v2`，健康检查 `/healthz`。流程为登录→选/建产品批→按账户类型选/建工序组→新建/修订草稿→发布。调用方固定填报标记、区分未知与零，抽检界面拦截LOSS。

迁移0006增加账户类型和历史基线，并删除旧业务数据；已有账户默认NORMAL，账户ID、密码、管理员标记和字典保留。部署前确认备份与删除范围，详见[迁移说明](migration.md)。reset-testdata仅用于明确可删除的测试业务，不随服务启动执行。

后端交付不包含外部前端或生产部署。文档中的设计要求、待核验项与实际验收须分开，范围见[交付状态](progress.md)。
