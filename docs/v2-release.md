# v2.0.0 发布说明

发布基线856f7df，已通过5e00380合入main；数据库迁移链0001–0006。项目阶段结论、合并信息和验收状态统一见[项目进度](progress.md)，发布过程明细见[归档原文](../archive/2026-11-04/pre-sync/docs/v2-release.md)。

## 交付内容

- NORMAL/SAMPLING账户自动标记填报类型，所有组/单变更按当前账户类型授权；管理员标记独立。类型变更撤销会话并清幂等缓存，密码保持。
- 产品批报告支持as_of历史回放与through_event_id固定视图，正式结果、初始草稿、修订草稿及取消独立展示；早于历史起点返回history_unavailable。
- 工序时间范围报告支持限定或不限产品批，分页明细与整个筛选范围的正式小计分开；两种检验类型独立统计。
- 保留完整纸面栏目、105格缺陷、可空计数与数量变化。保存追加不可覆盖版本，发布/修订/取消、slot与响应结果同事务。

## 调用方切换

所有认证、用户、字典、解析、业务和报告路径统一 `/api/v2`；`/healthz`不变。旧路径返回404，没有别名或按号upsert兼容。前端读取登录/me中的submission_inspection_kind固定填报标记，并承担抽检LOSS拦截。接口字段与错误口径见[API](api.md)。

0006新增账户类型和正式历史基线，删除旧业务表；旧账户默认NORMAL，密码/管理员标记/字典保留。显式reset-testdata仅用于已确认可清除的测试业务，不在启动时执行。部署和恢复步骤见[迁移](migration.md)及[运行说明](../backend/README.md)。

## 验收与部署范围

后端及当前工作区本地切换已有验证记录。外部前端、生产环境和其他目录的服务副本不因代码合并而完成部署。历史环境数量和服务状态仅作为阶段证据保留在归档，不作为实时状态展示。
