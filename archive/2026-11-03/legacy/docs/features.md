## 1. 系统定位

把纸质检验表单搬到线上的**"升级版在线文档"**：录入、留痕、检索、汇总。
**不做**审批流、不做流程管控、不做设备对接。

### 1.1 关键场景（本次澄清）

> **每道工序都要填一份表单，但各工序所填内容不同（具体差异尚未确定）。**
> 每道工序的人在前端找到**自己工序对应的那张表单**，填写相关项并提交——仅此而已。

由此确定的模型（与旧版的区别见 §8）：

```
表单提交 Submission（= 某工序填的那张表单，form_no 唯一）
├─ 纸质表头栏目（手写值，paper_*）
│    单位 / 送检人 / 送检时间 / 检验人 / 检验时间 / 操机员 / 交接员
├─ 计数区栏目
│    检验工序 operation_code ← 表单第一列，也是"找到自己工序表单"的依据
│    检验总数 / 合格品 / 不合格品 / 合格率（有明细时按明细重算）
├─ 样品信息           sample_raw（事实来源）+ 项目/型号/规格/大小/左右
├─ 系统留痕（与纸面人名无关）created_by / submitted_by / submitted_at / save_count …
└─ 明细行 Line（1..N）
   └─ 不良缺陷明细：35 列 × 凹面/凸面/双面 = 105 个计数格子

合计 117 个可填列 = 7 个纸质栏目 + 5 个计数栏目 + 105 个缺陷子列
```

### 1.2 第一设计原则：最大灵活性

| 编号 | 约束 | 对功能的影响 |
|---|---|---|
| F-1 | 不强制任何字段 | 任何列都可以留空保存 |
| F-2 | 不强制顺序 | 可以先填明细后补样品信息 |
| F-3 | 不强制完整性 | 允许"填了一半"，只提示不阻断 |
| F-4 | 不约束工序集合 | 未登记的工序按通用模板处理，开放全部列 |
| F-5 | 不假设使用环节 | 一次填完、多次补填都支持（字段级合并） |
| F-6 | 不收敛未知语义 | 各工序"具体填哪些列"未定 → 所有工序默认开放**全部列**，不设必填 |
| F-7 | 默认只警告不阻断 | 校验默认 `warn`；只有调用方显式要求 `strict` 才可能阻断 |
| F-8 | 可扩展优先于精确 | 工序/单位/样品段/缺陷列全部走目录或字典，加取值不改业务逻辑 |

## 2. 表单列目录（本次新增的核心内容）

### 2.1 纸质表头栏目（7 个，手写值）

> 需求 B-11：纸质表单既有栏目**全部纳入，不能省略**。这些字段名前缀统一为 `paper_`。

| 栏目 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 单位 | `paper_unit_id` / `paper_unit_text` | 字典 id / 文本 | |
| 送检人 | `paper_submitter` | 文本 | **纸面手写人名** |
| 送检时间 | `paper_submitted_at` | 文本 | 按录入原文存（如 `2026.9.8`），不做格式假设 |
| 检验人 | `paper_inspector` | 文本 | **纸面手写人名** |
| 检验时间 | `paper_inspected_at` | 文本 | 同上 |
| 操机员 | `paper_machine_operator` | 文本 | **纸面手写人名** |
| 交接员 | `paper_handover_by` | 文本 | **纸面手写人名** |

> ⚠️ **与系统留痕严格分离**：纸面上的"送检人/检验人"是手写人名；
> 系统的 `created_by` / `submitted_by` / `last_saved_by` 记录的是**实际登录用户**，仅用于追溯（B-17）。
> 两套字段并存，**绝不混用**。

### 2.2 计数区栏目（5 个）

| 列名 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 检验工序 | `operation_code` | 文本 | 表单第一列；也用 `operation_text` 保留原文 |
| 检验总数 | `total_qty` | 整数 | |
| 合格品 | `qualified_qty` | 整数 | |
| 不合格品 | `defect_qty` | 整数 | |
| 合格率 | `pass_rate` | 数值 | **服务端计算**（合格品/检验总数×100，总数 0 时为 null） |

### 2.4 工序表单模板

| 工序 | 说明 |
|---|---|
| `GENERAL`（一般检验） | 通用模板：开放全部列 |
| `一次加硬` | 已登记；当前同样开放全部列 |
| `二次加硬` | 已登记；当前同样开放全部列 |
| 其它任意工序 | **未登记也算合法**：按通用模板处理，开放全部列，不报错 |

> 业务方尚未确定"各工序具体填哪些列"，因此**一律开放全部列、不设必填**。
> 将来确定后，可在注册表里为某工序填 `allowed_fields` 收窄（不需要改业务逻辑）。

## 3. 功能清单

### 3.1 表单录入与保存

| 功能 | 说明 | 状态 |
|---|---|---|
| 新建表单提交 | 只需表单号（不给则自动生成 `YYMMDD-流水`） | ✅ |
| 工序选择与定位 | 按工序取表单模板与列布局（`GET /form-templates`、`/form-templates/:code`） | ✅ |
| **字段级合并保存** | 请求里出现的字段才改；未出现的保持原值 | ✅ |
| 三态语义 | 键不存在=不改；`null`=清空；有值=写入（缺陷格子同样支持 `null` 清零） | ✅ |
| 明细整体替换 | 提交 `lines` 即整笔替换明细（不做行级合并） | ✅ |
| 表头与明细的优先级 | 补丁里**显式给出**的表头栏目优先；否则按明细行重算 | ✅ |
| 服务端重算 | 合格率由 合格品/检验总数 计算 | ✅ |
| 完成度标记 | `is_complete` + `missing_fields`（工序/单位/检验人/样品/明细） | ✅ |
| 乐观锁 | 传 `expected_save_count`，不匹配返回 409 | ✅ |
| **幂等** | 请求头 `X-Idempotency-Key` 或请求体 `client_request_id`；同键重复提交回放首次响应 | ✅ |
| 批量提交 | `POST /forms/batch`，**整批一个事务**，任一张失败则整批回滚 | ✅ |
| 逻辑作废 | 标记 VOID + 原因，数据与明细保留 | ✅ |
| 未知字段报错 | 未知列名 → 400 并提示合法列清单（`GET /form-fields`） | ✅ |
| 表单号手工指定 | 允许调用方传 `form_no`（迁移期用） | ✅ |

## 4. 校验规则（V-1 ~ V-10）

> **默认 `enforce=warn`：全部只警告，任何内容都能保存。** 只有显式传 `enforce=strict` 时，标 ⛔ 的规则才阻断（返回 422）。

| 规则 | 含义 | 默认 | strict |
|---|---|---|---|
| V-1 | 合格品 + 不合格品 = 检验总数（三者全为 0 时不提示） | 警告 | ⛔ 阻断 |
| V-2 | 缺陷子项合计 = 不合格品 | 警告 | **警告**（已确认会重复计数） |
| V-3 | 某缺陷列三表面合计 ≤ 不合格品；单个子列 ≤ 检验总数 | 警告 | ⛔ 阻断 |
| V-4 | 所有计数为非负整数 | 警告 | ⛔ 阻断 |
| V-5 | 合格率 = 合格品 / 检验总数 | 计算（服务端） | 计算 |
| V-6 | 提交时间不得晚于当前时间 | 警告 | **警告** |
| V-7 | 表单号唯一；同一表单下明细行序号唯一 | ⛔ 阻断（409） | ⛔ 阻断 |
| V-8 | 样品信息与参考清单不匹配 | 警告 | **警告** |
| V-9 | 样品结构化项（项目）缺失 | 警告 | **警告** |
| V-10 | 表单栏目缺失（工序/单位/样品原始串/明细） | 警告 + 缺失清单 | **警告** |

> 一句话：**"数据自相矛盾"可以在 strict 下被拦住；"还没填完"永远不拦。**

## 8. 本次变更前后对比（重要）

| 方面 | 旧模型 | 新模型（本次） |
|---|---|---|
| 核心实体 | 一张纸质表单（Form）+ 多笔工序记录（FormRecord） | **一次表单提交（Submission）= 某工序填的那张表单** |
| 工序位置 | 在"笔"上 | 在**提交**上（表单第一列 `operation_code`），也是查询/统计主维度 |
| 明细 | 一行计数 + 15 个不良子项（点伤/划伤/脏污/加硬点/垃圾点 × 三面） | 一行计数 + **35 个缺陷列 × 三面 = 105 个子列** |
| 缺陷列清单 | 硬编码 5 类 | **字段目录驱动**（`formfields` 唯一事实来源，接口下发，新增列只改一处 + 一次迁移） |
| 表头与明细 | 明细为准 | 明细为准，但**补丁里显式给出的表头栏目优先**（贴合纸质"表头是合计值"的填法） |
| 字段级合并 | 反射 + 数据库列名 | **显式三态类型**（键不存在 / null / 有值），未知键报 400 并提示合法列 |
| 样品信息 | 表单级 | 提交级（每次提交都带） |
| 纸质人员字段（送检人/检验人/操机员/交接员） | 表单既有栏目 | **恢复为独立字段**（`paper_*`），与系统留痕 `created_by`/`submitted_by` **并存且不混用**（B-11/B-17） |
| 统计口径 | 按"笔" | 按**表单提交**（= 工序） |
