## 不恢复的内容

Form/Record旧模型、按form_no覆盖、自动表号流水、save_count可选锁、enforce/mode切换、客户端覆盖良率、null清零、日期原文冒充标准时点、全业务自由跨类型写入、旧幂等失败放行、旧接口路径、旧统计日期兜底、双业务域与候选导入均不适用。

Excel/CSV/PDF导出、个人资料修改、外部身份接入、IP限流与首次强制改密等历史计划不因被写在设计里就成为已交付能力。正式文档明确范围或待核验，避免以文字补齐掩盖实现不确定性。
